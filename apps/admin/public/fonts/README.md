# Licensed IranSans assets

Place the licensed webfont files supplied by the repository owner here:

- `IRANSansWeb.woff2`
- `IRANSansWeb_Medium.woff2`
- `IRANSansWeb_Bold.woff2`

The Admin references these stable public paths and falls back to system fonts
when the files are not present. Do not commit unlicensed font files.
