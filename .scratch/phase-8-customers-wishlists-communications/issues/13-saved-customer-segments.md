# 13 — Saved Customer segments

**What to build:** Marketing staff can create explainable reusable AND-filtered Customer segments and preview current audience counts.

**Blocked by:** 07 — Customer directory and detail workspace; 09 — Variant Wishlist.

**Status:** ready-for-agent

- [ ] Supported filters cover registration, ordering, completed value/count, purchased Catalog facts, and Wishlist facts.
- [ ] Segment definitions are bounded, typed, and never arbitrary SQL or expressions.
- [ ] Preview counts come from server projections and respect permissions.
- [ ] Segment edits do not rewrite already frozen Campaign audiences.
